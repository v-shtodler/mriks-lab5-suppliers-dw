# 4. Перехресне рецензування

Правило: ніхто не перевіряє власну роботу.

| Що перевіряємо | Автор | Хто перевіряє |
|---|---|---|
| Схема і діаграма | Архітектор | Інженер |
| DDL-скрипт | Інженер | Архітектор |
| Запити | Аналітик | Інженер |

## Що дивимось

- [ ] Діаграма збігається зі скриптом (ті самі таблиці й поля)
- [ ] У кожної таблиці є первинний ключ
- [ ] Таблиця фактів посилається на всі виміри
- [ ] Назви таблиць і полів в одному стилі
- [ ] Скрипт виконується без помилок
- [ ] Кожен запит працює і відповідає на своє питання
- [ ] Усі перевірки даних повертають 0
