# 4. Перехресне рецензування

Правило: **ніхто не перевіряє власну роботу.** Зміни потрапляють у гілку `main` тільки після перевірки колегою — так само, як переглядають програмний код.

Чек-листи складено за критеріями з лекційного матеріалу про командну взаємодію: норми проєктування сховищ, індекси, єдині стандарти іменування, відсутність архітектурних антипатернів.

| Що перевіряємо | Автор | Рецензент |
|---|---|---|
| Модель даних і діаграма | Архітектор | Інженер |
| DDL-скрипт | Інженер | Архітектор |
| Аналітичні запити | Аналітик | Інженер або архітектор |
| Опис області й задач | Аналітик | Архітектор |

## Чек-лист моделі

- [ ] Зернистість таблиці фактів описана одним реченням і зрозуміла
- [ ] Кожен вимір відповідає на питання «хто / що / де / коли»
- [ ] Є вимір «Період»
- [ ] У таблиці фактів немає текстових описів — лише ключі та міри
- [ ] Для кожної міри вказана категорія (адитивна / неадитивна)
- [ ] Діаграма збігається з DDL (ті самі таблиці й поля)
- [ ] Немає надлишкової денормалізації: у фактах не дублюються описи з вимірів
- [ ] Немає неконтрольованих зв'язків «багато-до-багатьох»: кожен факт посилається рівно на один рядок кожного виміру

## Чек-лист DDL

- [ ] Скрипт виконується з нуля без помилок
- [ ] У кожної таблиці є первинний ключ
- [ ] Усі зовнішні ключі фактів посилаються на виміри
- [ ] Типи даних відповідають змісту (гроші — NUMERIC, дати — DATE)
- [ ] Є обмеження NOT NULL і CHECK там, де це логічно
- [ ] Назви таблиць і полів в одному стилі (`dim_`, `fact_`, snake_case)
- [ ] Є індекси на зовнішніх ключах таблиці фактів
- [ ] Для великих обсягів продумано партиціонування (для навчального обсягу не потрібне — достатньо це зазначити)

## Чек-лист запитів

- [ ] Запит виконується на тестових даних без помилок
- [ ] Результат відповідає на сформульовану задачу
- [ ] Немає ділення на нуль (використано NULLIF)
- [ ] Відсотки рахуються з підсумків, а не як середнє відсотків
- [ ] До запиту є коментар із призначенням

## Чек-лист тестів цілісності

- [ ] `sql/tests/03_integrity_checks.sql` виконується без помилок
- [ ] Усі 12 тестів повертають 0 порушень
