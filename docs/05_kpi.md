# 5. Оцінка результативності

> Шаблон. Цифри заповнює команда наприкінці спринту за даними дошки й історії репозиторію. Показники варто звірити з матеріалом про командну роботу, який викладачка розмістила на платформі.

## Показники

| Показник | Формула | Звідки дані |
|---|---|---|
| Виконання етапів | закриті задачі / призначені задачі × 100 % | дошка проєкту |
| Дотримання дедлайнів | задачі, закриті у строк / закриті задачі × 100 % | дата закриття Issue |
| Якість артефактів | кількість зауважень рецензента на одну задачу (менше — краще) | журнал зауважень, коментарі в PR |
