# 3. Команда і спринт

## Ролі

Обов'язки поділено між двома спеціалістами. Імена не вказуємо, тільки ролі.

| Спеціаліст | Ролі | Що робить |
|---|---|---|
| Спеціаліст 1 | Архітектор даних + аналітик | придумує схему, малює діаграму, описує задачі, пише запити |
| Спеціаліст 2 | Інженер даних + тестувальник | пише скрипт створення таблиць, розгортає базу, готує тестові дані й перевірки |

Усі дії в репозиторії зроблено з одного акаунта. У коментарях до задач на початку вказано, від імені якої ролі написано коментар.

## Трекер

Задачі ведемо на дошці GitHub Projects: `Todo` → `In Progress` → `Done`. Роль видно за міткою задачі.
