# ЛР5 МРІКС — сховище даних «Надійні постачальники»

Командна лабораторна робота №5 з дисципліни «Моделювання та розроблення ІКС».

**Ідея:** відділ закупівель хоче знати, які постачальники сировини надійні — привозять вчасно і без браку.

**Що зроблено:** сховище даних за схемою «зірка» в PostgreSQL — одна таблиця фактів (поставки) і чотири виміри (період, постачальник, матеріал, склад).

## Команда

| Спеціаліст | Ролі |
|---|---|
| Спеціаліст 1 | Архітектор даних + аналітик |
| Спеціаліст 2 | Інженер даних + тестувальник |

Усе зроблено з одного акаунта; роль автора вказано на початку кожного коментаря в задачах.

## Як запустити

```bash
createdb suppliers_dw
psql -d suppliers_dw -f sql/ddl/01_create_dw.sql
psql -d suppliers_dw -f sql/dml/02_sample_data.sql
psql -d suppliers_dw -f sql/queries/analytics.sql
```
